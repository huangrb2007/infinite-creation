# 镜头数量与角度夸张程度

机位先服务剧情转折，再通过具体几何改变画面。在 BCF 的 4、5 档，把摄影机相对人物和地标的位置、可见的透视变化写进正文，并在 `controlDesign` 逐字引用。4 档至少覆盖半数镜头，至少两镜（单镜时一镜）。5 档至少覆盖四分之三，多镜稿使用至少两种不同机位；其余镜头可用于建立关系或看清后果。对话模式微调按本轮文字设计。

用户或软件提供设置时，在研究之后、分镜之前锁定。镜头数量和机位强度独立于动作速度、动作密度、故事时长与人物能力。显式设置优先于技能中的高节奏打斗默认；未设置时按故事选择，不凭空施加固定镜数。

## 镜头数量：0–20，整数

0 为 AI 自主决定：根据情节、情绪节拍、动作与总时长选择合理的 1–20 镜，可以一镜到底或多镜剪辑，不套固定镜数。0 是自动档，不是零个镜头；先自行调整镜数与时间分配，仅在必需剧情与总时长仍无法兼容时澄清。

选择 1–20 时严格等于所选数量，不是上限、建议或动作数。1 表示一镜到底：摄影机路径、焦点和人物调度连续，允许镜内改变景别与角度，不允许切镜、暗切、遮挡偷切、时间跳跃或把连续镜拆成多个 Shot。多镜围绕信息变化、情绪转折和动作因果分配时长，切点保留承接证据。20 镜不等于20次攻击；不能复制起手、重复命中或擅加剧情凑数。按总时长容纳动作，必需动作与镜数/时长确实冲突时澄清，不能擅改用户设置。

## 角度夸张程度：1–5，整数

| 档位 | 设计要求 |
|---|---|
| 1 标准 | 自然透视、稳定地平线、常规平视与适度仰俯拍；不使用超广角、极限仰俯拍、强倾斜或贴脸畸变。打斗动作仍可大开大合、有重量 |
| 2 轻度 | 常规机位为主，情绪/动作重音用轻低机位、高机位或适度广角 |
| 3 明显 | 在转折处用前景遮挡、低机位或高差构图改变观众能看见的信息 |
| 4 强烈 | 让前景尺度、遮挡揭示或路线纵深显著改变画面，保留看懂后果的窗口 |
| 5 极限 | 组合至少两种有对比的透视视点。单镜沿可达路线改变高度或前后景关系 |

高档不自动加快剪辑、增加攻击或把文戏改成打斗。文戏可用俯拍表达孤立、低机位表达压迫或决断、近前景表达关系，但含义由具体剧情决定，不是固定情绪公式。相机运动幅度也不等同于角度夸张程度。

每镜把“情绪/战术变化 → 观看目的 → 机位高度、视线方向、透视与运动 → 可读结果”写成具体画面，不只标“夸张5”。一镜到底也在镜内按情绪变化调度视点。超广角保留同一CG身份，避免脸和武器贴边失形；人物实际间距、轴线、动势和接触点不随换角度改变。复核自动档镜数合理且在1–20内，手动档镜数精确一致、单镜无暗切、每个极端视点有动机、接触可读、跨镜状态继承。

## 把夸张角度拍出来

| 机位 | 可见的画面变化 |
|---|---|
| 贴地仰看 `ground-skimming` | 从可站立一侧贴地斜拍。前景的靴底、台阶或兵器占画变大，人物和远端地标仍可辨 |
| 陡俯斜看 `steep-overhead` | 从台阶上方、屋梁旁或其他可达高位斜切向下，把相对间距、错身路线或落点留在画内 |
| 沿纵深看 `near-axis-depth` | 沿桌沿、巷道或运动线稍偏一侧看，使近处动作和远处目标处在不同深度。先核眼线、遮挡和透视比例 |
| 掠过前景 `foreground-parallax` | 让柱、门框或护栏在摄影机近旁快速移过，远处角色位移相对小，借视差揭示其位置和退路 |
| 偏位倾斜 `canted` | 先改变机位的高度或偏移，再让有意义的栏杆、墙角或地平线形成斜向构图。单纯滚转画框无法提供 5 档所需的透视变化 |

例如追逐沿桥向东推进，可先从桥南侧断栏旁贴地斜仰，断栏在画左放大，角色向东跨过桥面裂口。下一镜仍从南侧高位陡俯，先接住人物在裂口东侧的落脚，再看清东端出口。两镜高度和透视反差明显，人物路线、支撑脚和出口方位仍能对上。
