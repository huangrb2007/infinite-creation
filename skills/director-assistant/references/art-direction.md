# 审美设计与返修依据

在研究后、分镜前使用；新稿、局部修改和研究受限稿采用同样的设计底线。先组织观众看到的关系，再写质感措辞。这里只检查设计；没有可读取的成片时，不宣称实际构图、表演或视频审美通过。

## 意图、风格与底线

用户指定的剧情、动作、时长、镜数、渲染档位和强度属于当前约束。高饱和、大规模特效、极端机位、小景别与关键慢镜可以承担明确表达；不得以审美优化为由暗中降强度、删动作、改结尾或统一成低饱和慢文戏。技能中的高节奏打斗默认与显式滑块仍按现有规则执行，完成手法数量不能代替主次和因果检查。

共同底线是观看重点、必要信息可读、画面关系相容与情绪推进。高强度通过轮廓、纵深、亮度分配、先后次序和后果建立层次。允许有动机的短暂遮挡、过曝、停留、重复、对称和多人并重；检查前后是否兑现意图，不机械要求每镜只有一人、每镜换机位或每秒出现新动作。约束确实冲突时说明具体位置和可行取舍，不静默覆盖用户决定。

## 六项决定：从失败定位到修改

BCF 的 artDirection 保留以下六项，即使研究受限也须填写。每项指向当前镜头中可见的安排，不用质量标签凑字数。

| 字段 | 应确定的画面关系 | 失败表现 → 优先修改 |
|---|---|---|
| intent | 观众先知道/感到什么，哪一刻改变理解；人物想做什么 | 只有“悲伤/燃”，行为无转折 → 从已有事件设计可见的选择或反应，调整揭示时机 |
| visualHierarchy | 此时主要观看对象或人物关系，轮廓、面积、纵深、明暗和运动怎样引导视线 | 特效、脸、背景同时抢眼，关键接触重叠 → 调视点、错开动作峰值、分离背景；保留动作与规模 |
| lightColor | 既定世界光源、主要色彩关系、局部强调与材质响应 | 全屏等亮、每色都强调、跨镜随意换光 → 组织明暗与色块，把强调放在当前重点；不用统一降饱和修复 |
| rhythm | 哪个变化值得读清，何时推进，声音和动作如何交接 | 每击同等爆闪/慢放，或细节装不进时长 → 重分配镜内先后、镜长和强调位置；保留指定动作、镜数与关键慢镜 |
| signature | 由本场景人物、道具或空间产生的一个可记忆变化，并指出镜头 | 换任何角色和场地仍完全一样，靠额外奇观撑场 → 用已有关系形成具体落点；简单场景不强塞惊奇 |
| restraint | 为主效果让出注意力的非必要处理；也可说明为何当前复杂度成立 | 特写、运镜、音效重复表达同件事 → 合并/错开获准改动的处理，或保留承担升级和回返的重复 |

先内部比较两个简短可行方向，再选择适合当前目标与约束的一种；无需输出两份完整提示词或新增用户确认。差异来自观看位置、信息释放、调度或光色组织。向用户提出画面备选时也应用本表，不能把明显失焦或超载的方案当作有价值的选择。已给足拍法或局部微调时，聚焦相应范围。

## 参考与样例

实际研究沿用 [scene-research.md](scene-research.md)：优先用户指定的维度，再查具体已发行作品片段、分镜或制作人员解析。一般教程、海报和片名不能承担动作过程证据。比较不同作品的具体处理，并记录 work、scene、technique、来源逐字 evidence、adoption 和 shots；采用点必须能在正文定位，不照搬整段招式或原作道具。

来源只有文字时，只据其明确记载设计，不冒称看过画面或编造时间码。可读取静帧可校准构图、光色、轮廓与材质；调度、节奏和动作承接需要连续片段。没有视觉证据时，只作文本设计判断；原有研究受限标记仍适用。

需要设计对照或找不到具体修法时，按 [审美正反例](aesthetic-examples.md) 的索引只读最相关的一两组。这些是待用户认可的原创文字设计，不是真实影片分析、已验证成片或用户已认可的审美标准；不可拿来充当联网案例证据，不因样例而增加未授权剧情。维护者可用用户认可的截图/片段和实际结果逐步校准。

## 审核与维护

在现有 CG/表演审核开头按 [quality-gate.md](quality-gate.md) 记录最明显的一两处实际问题及修订后的镜头依据；原稿成立可保留，不为凑数找错。修改后复核用户约束、相邻切点、光源与时间。引用与字段通过只代表可追溯，不代表美感得到认证。

维护或评估框架变化时使用 [六道固定对照题](aesthetic-benchmark.md)，日常出稿不加载评测表。分开记录文本设计比较和真实成片比较，不把模型自评分当作用户审美结论。

制作依据：[Disney Layout](https://www.disneyanimation.com/process/layout/) 说明以分镜和粗动作迭代机位、构图与情绪；[Disney Lighting](https://www.disneyanimation.com/process/lighting/) 说明用色彩和光照引导注意力并支持故事。这些制作方法支持上述应用设计，不是 H3 能力或效果保证。
