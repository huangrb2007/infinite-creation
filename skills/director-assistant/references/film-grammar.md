# 连续性与剪辑依据

## 1. 先确定观众知道什么

每个叙事节拍确定「人物想要什么、遇到什么阻力、什么发生改变、观众此刻应知或暂不知什么」。镜头至少承担揭示、隐藏、关系变化、情绪、因果、空间或节奏中的一项任务。删去它若不损失信息、体验或必要呼吸，考虑合并。

多镜、复杂交互或连续性修复使用 [continuity-ledger.md](continuity-ledger.md) 的状态交接流程：先建立世界关系和各镜初末态，再写提示词。世界方向、人物自身左右与画面左右分开；摄影机变化后重新核算。每个连续切点都要有具体末态 → 初态依据，不能只写“空间一致”。不必向用户输出调度图或台账。

## 2. 默认必须守住的连续性

- **180°与银幕方向：** 同一互动段的切换保持在已建立轴线同侧；对视双方视线方向相对，高低、距离感匹配。追逐与投射物的运动方向可追踪。不能仅为拍到正脸把人物写成背对目标。
- **空间更新：** 开场在剧情需要前交代必要关系，可由细节逐步揭示，不强制大远景开头。换位、转弯、大位移或主导互动对象改变时，通过可见走位与关系镜明确新轴和新方向。中性正轴镜、插入特写、甩镜或遮挡都不是“越轴许可证”；默认不主动设计跨轴机位。用户要求跨轴时明确路径、目的和之后的空间锚。
- **视线与注意力：** 看向目标—目标镜需匹配目线高度与方位；明确主观镜属于谁，避免无缘由漂换视点。重要物/动作切前切后尽量落在容易接住的注意力区域；需要观众重新寻找时给读取时间。
- **动作接续：** 在可辨识的动作相位切出，后一镜从这段运动的下一瞬间接住姿态、速度、受力和空间，不重演上一阶段。不可因换角度让同一击重打一次、持物换手或接触提前发生。动作可跨镜完成；关键因果须可见或由符合叙事意图的明确画外证据/有意省略交代。
- **状态持续：** 服装、武器、碎片落点、损伤、湿润程度及主光方向有连续变化理由。离开参照物后它的距离和视差要变化；新角度不能让人物瞬移回原位。
- **相邻镜可辨识：** 同主体同场景的连续切换应有足够视角、景别或信息变化。30°是避免意外跳切的经验参考，不是数学保证；不设强制“跨两档”或景别跨度上限。近似构图造成跳动时，改机位/镜长或并入连续运镜。用户明确要求跳切时交代时间省略或心理目的。

## 3. 给每个切点选对关系

内部只需写清「为何此刻切、凭什么连接、观众应推断什么」。最终提示词用实际画面与声画时序实现，术语不能代替内容。

| 需求 | 可选手法 | 切点必须落实什么 |
|---|---|---|
| 同一动作跨视点 | 动作匹配 / 动作中切 | 切在可辨动作相位；接上轨迹与接触点，不丢关键因果，不无意重复时间 |
| 人物理解、怀疑、回应 | 视线匹配、正反打、反应镜 | 眼神看谁、看见什么、信息怎样改变反应；不必每句台词换镜 |
| 场景接续或情绪余韵 | 声桥、J-cut、L-cut | J 是下镜声音先于下镜画面进入；L 是上镜声音延续到下镜画面，写明声源与相对切点的起止 |
| 同时发生的两条行动趋向交汇 | 交叉剪辑 | 先让两处可辨，建立同时性线索与共同危机；切回时状态合理推进，不把时空关系藏成错误 |
| 比较两个人、时代或处境 | 平行/对比蒙太奇 | 具体对应动作、构图或情境；不凭交替出现暗示它们必定同时发生 |
| 跨时空连接或有意省略 | 图形、动作、声音匹配；省略剪辑 | 指出相似形状/方向/声音及变化后的时空状态；匹配顺滑不等于事件连续 |
| 压缩一段过程 | 段落蒙太奇 / 积累 | 选择能证明进展的阶段与变化，明确耗时/状态变化；不能用无关漂亮镜头顶替进展 |
| 推动压力或情绪 | 节奏、音调/情绪蒙太奇 | 节奏来自动作内部运动、镜长、音响和信息负荷；情绪来自光色、尺度、表演、声音的组织，不只是加快 |
| 让两幅画面产生第三层意思 | 联想、隐喻、观念蒙太奇 | 写明具体并置及其可理解的语义联系；不篡改用户剧情或误称为同一空间 |

“度量”偏向镜长组织，“节奏”还回应画内运动；“复合/超音调”综合多个感知层。只在它们解决当前叙事问题时使用，不按理论名称凑齐目录。叙事关系与节奏组织可以叠加，但保持一条清晰的主要连接逻辑。

默认画面硬切，声音可跨切点连续。叠化、淡入淡出等只在用户要求或明确转场需求下设计，并遵守当前 H3 指南；它们不是修补空间错误的工具。跨时空有意省略无需保持字面状态相等；连续动作则必须保持可追踪的状态承接。

## 4. 切点微例（理解关系，不复用固定节奏）

- A 手在画右伸向桌上信封 → 手未触及时切同侧近景 → 指尖接住同一段运动并压住信封；切点让“犹豫是否拿走”变得可见。
- 卫兵望向画左上方 → 切其所见楼梯入口 → 后镜的脚步声提前进入：视线匹配与 J-cut 可以共同制造预期。
- 她举起旧钥匙 → 匹配切到另一年代同位置的钥匙落入锁孔：属于跨时间联想，不能声称是同一动作无缝完成。
