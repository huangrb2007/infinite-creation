# 内部质量闸

先修正，再交付。检查针对本稿实际内容，不用逐项报告给用户。三轮分别进行，避免被漂亮措辞掩盖逻辑问题：第一轮逐镜检查三大角色视觉档位（默认 3DCG 档、游戏内三渲二实机建模档或真人电影档）与微表情表演，第二轮检查特效质感，第三轮按事件线逐对检查切点和空间，再核总体叙事、时间与 H3 格式。无特效时略过第二轮。

## 前置硬闸：联网研究与创意落实

逐镜核对用户选定的片段与采用范围。用户提供的参考主导其指定维度，补查案例仅补足具体问题。只读到文字时注明证据类型，无法核实的片段细节与时间码不作为事实。

按 [scene-research.md](scene-research.md) 核查，不能用后面三轮的技术正确替代本项：

- 联网可用且用户未禁止时，是否在设计前实际检索并打开了相关来源，比较至少两个不同处理的有效案例；同场景微调复用的研究是否确已核查且仍适用。
- 战斗研究是否覆盖分镜、动作因果和人物/摄影机调度；是否区分实际观察、来源解释与本稿推导，未把摘要、孤立图片、记忆或不可访问视频当作已看过的过程。
- 正文中能否定位研究转化的具体选择；新设计的战斗须落实动作、调度与镜头/节奏，局部优化则在获准修改处落实，其他维度核查并继承用户锁定内容。只贴链接、作品名或“参考某片”不通过。
- 交锋或争吵挽留戏是否因人物目标、距离、地形或主动权而动态推进；无理由重复站定互打、开场站桩正反打对话或等时长碰撞特写时，返回场面设计修正。
- 来源与采用点是否按交付要求可核查；实际离线、用户禁网或搜索证据不足时，是否如实说明并标记研究未完成/受限，未把草稿宣称为完整验收通过。

有可用网络却跳过研究，应先补研究并据此复核设计，不直接交付为成稿。外部条件确实受限时按 scene-research.md 继续草稿流程，不伪造通过。

## 用户镜头设置与质感词库

强档位核对 controlDesign 的普通版对照与正文差异：速度改变动作经过屏幕的时间，密度改变连续动作与停顿结构，摄影强度改变可见视点和透视关系。证据须在实际镜头描述内；只在全局头部加倍率、不改变正文的稿件返回设计。角度 4 至少半数镜头有明确的透视变化（单镜一镜，多镜至少两镜）。角度 5 至少四分之三镜头有明显的高低、纵深或前景尺度变化，多镜稿至少用两种不同机位，其余镜头可交代关系和后果。

有镜头设置时按 [camera-controls.md](camera-controls.md) 核查 0 自动档按故事选择合理镜数（1–20）、手动档精确镜数、单镜无暗切、角度档位与剧情情绪的对应，以及接触和连续性；角度 1 优先于技能的夸张机位默认。质感措辞按 [look-vocabulary.md](look-vocabulary.md) 对应档位取舍，不能用数字人、瓷白皮、固定棚拍或质量口号覆盖用户设计；确认所选词已落实为可见体积、材质、光源和色彩关系。

## 第一轮：角色视觉档位（3DCG / 三渲二 / 真人电影档）与多拍微表情表演

先按 [art-direction.md](art-direction.md) 的六项决定核对当前镜头；本项在联网受限和局部修稿时同样执行，复用本轮，不增加审核轮数。保留用户的风格、强度、剧情和时长；高饱和、大特效及夸张视点不自动构成缺陷。需要对照时只读 [aesthetic-examples.md](aesthetic-examples.md) 中相关的一两组；这些文字示例未经用户逐条认可，不能作为真实影片或成片证据。

按 [cg-look.md](cg-look.md) 核对当前选定的视觉档位，保持三套档位独立、绝不混用词条：

- **默认 3DCG 档：** 核对 12 项约束（CG 媒介、角色雕塑、皮肤/面颊底色、CG 表情形变、眼口、发型受光、发丝动力学、布料动力学、身体动作、材质分离、美术光影/世界光源、时间稳定）。
- **游戏内三渲二实机建模档（用户指定“三渲二”时）：** 核对《鸣潮》《绝区零》《崩坏：星穹铁道》实机模型专项约束：
  1. **与 3DCG 及真人区分：** 确认未混入 `FINAL FANTASY VII REMAKE`、`soft subsurface scattering`、`fine natural skin microstructure` 或真人实拍词条。
  2. **保持三维实机体积：** 确认锁定具有三维几何体积与空间透视的 `in-game 3D cel-shaded character model`，未写成 `2D illustration`、`splash art` 或 `flat 2D anime`。
  3. **三渲二特征完整：** 核查 SDF 面部平滑二分光影（无鼻翼/眼窝脏黑自阴影）、纯净无毛孔卡通肤质与克制面颊底色、多层高光二次元瞳孔与 3D 绑定口型、三维几何发束与条带高光（specular band）、风格化 PBR 金属/皮革/布料材质分离、极细本色描线与利落硬边轮廓光。
- **真人电影档（用户指定“真人 / 实拍 / 真人电影质感”时）：** 逐镜执行「五项硬闸」核查：
  1. **杜绝深法令纹（全局+逐镜双重锁）：** 确认全局与每个说话/哭泣镜头均显式锁定 `youthful smooth uncreased cheeks, completely flat and smooth nasolabial transition with zero nasolabial folds or marionette lines, and minimal jaw opening`，未写任何会导致鼻翼至嘴角深沟、木偶纹或刀刻皱纹的描述。
  2. **杜绝油腻/塑料皮肤：** 确认皮肤锁定 `natural matte skin finish, soft diffused reflectance, zero oily sheen or plastic specular glare`。
  3. **杜绝高对比度与高饱和度（含高危色彩物降饱和）：** 确认影调锁定 `heavily desaturated, low-saturation cinema color grade, smooth logarithmic highlight roll-off, soft low-contrast diffused lighting, lifted milky shadows`，且正文中所有暖黄灯、红电话亭、红围巾等鲜艳物均已添加 `muted` / `pale` / `dusty` 降饱和修饰。
  4. **彻底清除 `FACS` / `AU` 代码缩写：** 确认最终 H3 英文提示词正文中**零出现** `FACS`、`AU1`、`AU4`、`AU7`、`AU17` 等学术缩写，已全部转译为具象解剖可见描述。
  5. **杜绝用力过猛与杜绝面瘫（多拍微表情验收）：** 确认关键近景/特写包含 3–4 个按时序演进的微表情节拍（`first... second... third... fourth...`）——如挽留方边说边蓄泪并在气口眨眼时缓慢滑落单滴眼泪（跨镜保留湿润泪痕），想离开方眼泛泪光却偏头 30° 拒绝直视、闭眼叹气并不耐烦打断台词。

面部与光影分开验收，以下任一问题先返修：

- **多视图来源与侧面朝向对齐：** 若为上方脸部特写、下方全身三视图，正文须明确上方是唯一面部身份来源，下方正面/指定侧面/背面只供各自身体、衣装、装备与整体轮廓。**特别核查侧面全身图的朝向：若参考图为“正左侧面全身图”（人物面朝画左），仅在分镜中人物朝画左或从右向左移动时直接引用该侧面轮廓；严禁在人物位于画左面朝画右时错误引用正左侧面图！**

依据 [vfx-design.md](vfx-design.md) 和 [vfx-families.md](vfx-families.md) 当前类别，检查正文中的主要效果，而非只查风格总述。无特效时略过本轮。

## 第三轮：切点与空间

使用 continuity-ledger.md，实际比较每个连续切点的 `前镜末态 → 后镜初态 → 新变化`，包括时间、世界位置/朝向、机位/轴线、动作相位、持物/接触/支撑、面颊湿润泪痕、衣发余波、特效阶段及残留和世界光源。反查正文是否保留了台账所依赖的证据；只有内部算对、提示词没写出来，也未通过。

### 切点矛盾与空间硬闸

以下任一未解释的矛盾都必须先返修：

- **【高危】目送离场戏的「正面特写 vs. 后景背影」180°/前后景空间悖论：** 前镜 B 背对 A 走远，后镜切到 **A 的正面脸部特写（相机在 A 正前方往回拍 A 的脸）**，却仍在后镜写“B 的背影在 A 身后的背景（background）里越走越远”！一旦发现此类正反打前后景颠倒，必须立即返修：拍 B 远去背影用**越过 A 肩膀的后方机位（前景 A 背影 + 远景 B 背影）**；切 180° 反打拍 **A 的正面特写**时，B 必定已向**镜头前方画外（camera-front / off-screen foreground）**走远，**A 身后的背景只能是反方向的空街道与静止地标**！
- **【高危】多视图侧面朝向与银幕方向颠倒：** 角色位于画左朝画右（展示解剖学右侧），却在提示词中写匹配“正左侧面图（anatomical left-side profile）”。
- **【高危】争吵/挽留戏原地站桩单调调度：** “B 想走、A 挽留”的戏份缺少边走边追、拉手急停、抓手宣泄、用力甩开手离去的动态位移链。
- **【高危】跨镜泪痕丢失：** 前镜已经写眼泪滑落面颊，后镜切回同一人脸部特写时未写 `preserving the glistening wet tear track on the cheek` 导致泪痕凭空消失。
- 某次攻击只写“互殴/拳脚相撞/兵器碰撞”，没有实际接触双方的具体侧别与部位；武器只标一方段位，或瞄准部位和实际格挡/命中部位混为一谈。
- 前镜横向飞行，后镜凭空改成原地竖直下坠；上升/下降阶段、水平/垂直速度或轨迹无依据重置。
- 连续切点重复起手/命中，或上镜未接触、下镜已完成交接/受伤/击飞；抓手与松手之间缺少甩开或释放过程。
- 世界位置、相对高度、间距或落点重置；自身右侧与画右混用；机位和所写画面左右矛盾。
- 朝向、追逐或投射方向反转，无可见转弯、新轴或明确时间关系解释。

交付前不得留下未解决的连续性矛盾；最终再从提示词正文独立重建一遍运动事件线，确认它表达的是已核对的轨迹。
