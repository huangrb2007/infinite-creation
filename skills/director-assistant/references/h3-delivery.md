# H3 衔接与精炼交付

## 格式与素材

先读 `h3-prompt-writing/SKILL.md`，再按它选择对应参考指南。Ref2VA 中共用的镜头、声源等规则按其指向读取。不要改动依赖技能，也不要在此维护另一套字段、标签或时长规格；依赖缺失时定位并说明，不能声称已经符合 H3。

- **文字故事：** 无参考图可直接走相应文字模式，不要求用户另造素材。人物/场景设计信息由文字给出。
- **角色/场景参考：** 使用用户指定的编号和用途，不扫目录补图、不猜映射。仅定义外观的素材按角色/场景设计引用，不扩写外貌、不照抄其站姿、背景或构图；按用户既有习惯，不为外观复述额外读图。用户已明确分区时直接采用；若需识别多视图版式、用户要求图像分析，或首尾帧/构图任务必须理解图像，则实际查看可用图像，细节不清时放大相关区域，不能伪称看过。
- **多视图：** 对用户指定或已确认的“上方一张大面部特写、下方从左到右为正面全身／正右侧全身／背面全身”版式，按下节分区锁定，不再套用“最左格取脸”。其他版式按其实际分区和用户用途处理，不把上方或最左当成所有参考图的固定规则。
- **首尾帧/构图锚：** 明确它在何时成为画面，路径、朝向、物体状态与镜头终点可达；不可用新设计开场覆盖用户首帧。FL2VA 的单/多镜规则以 H3 为准。
- **素材媒介冲突：** 真人照片或二维立绘作为身份/设计参考时，可按用户选定的目标档位（**默认 FF7RE 3DCG 档** 或 **游戏内三渲二实机建模档**）转译并保留身份；被明确指定为必须原样保留的实际首/尾帧时，默认档位不能覆盖该帧。若用户同时要求原样真人帧与全片纯三维动画，具体指出这一个冲突并解决素材用途或帧版本，不能假称已同时满足，也不擅自生成替换图。只有默认风格与明确帧要求冲突时，直接以用户帧要求为准。
- **属性覆盖：** 身份、动作、表情、场景、渲染分别指明来源；用户明确要求的属性覆盖只影响该属性。表情参考不能替换身份，3DCG 或三渲二质感升级不能偷偷改变角色五官和服装。
- **角色三大视觉档位与光影分工（3DCG 档 / 三渲二档 / 真人电影档，严格区分）：**
  - **默认 3DCG 档：** FF7RE 负责角色 CG 造型、皮肤、衣发材质和动画质感；MJ 参考只取用户要求的光影属性，不顺带复制参考人物的脸型、妆容或真人皮肤。
  - **三渲二实机建模档（用户说“三渲二”时采用）：** 按 [cg-look.md](cg-look.md) 第二部分把**游戏内 3D 实机角色模型风格**写入提示词。指定单一作品时以其外观为锚；只给“三渲二”时直接描述所需的可见特征——锁定三维建模几何体积、SDF 面部平滑二分光影（clean 2-tone cel-shaded facial ramp）、纯净无毛孔卡通肤质、三维几何发束与条带高光、风格化 PBR 金属/皮革/布料材质分离，以及极细本色描线与硬边轮廓光。三渲二档不混入 FF7RE、皮下散射或写实毛孔词条，也不把三维实机模型写成 2D 平面立绘。
  - **真人电影档（用户说“真人 / 实拍 / 真人电影质感”时采用）：** 按 [cg-look.md](cg-look.md) 第三部分与 [acting-performance.md](acting-performance.md) 把**院线大画幅胶片/ARRI 光学实拍质感与 FACS 内敛微表情演技**写入提示词——首镜与近景明确锁定平滑饱满的鼻唇过渡（无深法令纹）、自然哑光微绒肤质（无油腻塑料反光）、对数高光柔和滚降与低对比低饱和电影调色，以及中下脸松弛、靠眼神与微呼吸传情的克制银幕表演。
  - 用户明确要求减淡腮红时，保留原肤色与身份，不能用“完整保留外观”抵消修正；实际首尾帧原样保留的冲突仍按“素材媒介冲突”规则处理。H3 正文用可见属性表达，不迁入 `--sref`、`--stylize` 等 MJ 参数。

跨字段核对素材定义、概述、保留说明与逐镜正文中的取景、时间和渲染要求。外观完整保留不等于全身入画，保留二维角色设计不等于沿用二维平面渲染；关键画面约束写进对应正文，其他字段不暗含相反要求。修订材质或场景时，同步复核受影响的反光、接触声和残留状态。

### 上方面部特写 + 下方全身三视图

同一张图中的四个区域是同一角色的分工参考，不是四个人或四个镜头。布局已明确时直接执行，不要求用户重复标注，也不必裁图才能写提示词。

| 区域 | 允许提供的角色属性 |
|---|---|
| 上方大面部特写 | **唯一面部身份来源**：脸型、骨相、五官及其比例、眼形/瞳色、鼻唇与颌线、面部肤色和妆容；脸周发际线与刘海也以此为准 |
| 下方左侧正面全身 | 身体与头身比例、肩腰胯和四肢、正面衣装层次、装备位置、鞋靴与整体轮廓；不取其脸型或五官 |
| 下方中间正右侧全身 | 用户指定的右侧身体轮廓、厚度、衣装侧面结构、装备前后关系及垂挂位置；不取侧脸、鼻尖或下巴轮廓来重塑面部 |
| 下方右侧背面全身 | 背部衣装、背带与装备、后侧鞋靴、后发长度与整体发型背面轮廓；不反推新面部 |

“下方左/中/右”指图片格位，“正右侧”指用户指定的角色视图；不能只因人物面向画面右方就自行判断解剖侧别。非对称装备按用户标注与可见对应关系保留，不为配合格位而镜像。

**面部来源排他。** 下方即使有清晰脸部也不参与平均、拼接或覆盖上方脸；灰色、空白、被遮盖或简化的脸只是未提供面部信息，不能生成灰面、面具或无五官角色。侧脸和转头仍由上方同一面部身份作三维延续，不切换为下方头模；单张正脸未提供的深度关系保持一致、保守补全，不声称参考已给出全部侧脸细节。下方可决定头部相对身体的整体尺度，不可重定脸内比例。脸周发型按上方，长度与后方体积由下方补充；分区冲突按上述属性归属处理，用户明确覆盖优先。

**把分工写进交付正文。** 在 H3 允许的素材说明及主体字段中，使用用户原有图号/标签明确“上方只锁脸、下方三视图只锁身体衣装”，不只保留在内部分析，也不替四个区域虚构四个独立素材标签。可按依赖规范的实际标签及当前档位改写这段自然语言：

`Use only the upper facial close-up in the supplied character sheet for facial identity in every view, including speech, expressions and turns. Use the lower front, designated right-side and back full-body views for body proportions, clothing and equipment; lower-view faces do not contribute to the face. Preserve one coherent 3D character, with the upper portrait's facial identity carried through all head angles.`

该图默认是角色设计参考：不继承拼版、展示站姿、灰色背景或灯光，不把上方特写规定为影片首镜，也不要求成片展示三视图。3DCG 档或三渲二档的克制腮红与光影规则仍按 [cg-look.md](cg-look.md) 执行。用户若明确指定整张拼图为必须原样保留的首/尾帧，按其帧要求处理；若又同时要求该帧是单人场景，指出这一具体冲突，不能悄悄改素材用途或换首帧。

## 把内部设计写成可执行画面

按 H3 主体字段，短句确认风格（默认 3DCG 档、游戏内三渲二实机建模档或真人电影档）后立即进入开场构图与事件。逐镜写清主要可见主体/关系、机位、焦点、动作与结果、切点和当下声音；不把内部检查字段表逐项粘进正文。

全局风格、固定场景、持续天气的完整基准只说一次；风险镜按 [cg-look.md](cg-look.md) 对应档位补局部身份锚，包括可辨口型的普通对白与微笑，不只强情绪。把“具体口型/表情 + 同一三维模型体积 + 对应档位的表面与光影延续”融入对应动作句，按当前风险裁剪，不逐句重复长禁令。每个连续切镜开头把内部末态 → 初态写成一句可见承接：动作镜写相位/接触及关键空间/持物，静态反打、反应或 POV 写姿态、目线目标、情绪或声画关系。不能只写“继续/无缝承接”，也不能以精炼为由删去这些信息。时间省略、同时交叉和联想按各自关系写清，不强求字面状态相等。

连续运镜是一条有起止的路线，镜头切换则按 H3 明确标记。不能一边写“无切镜”一边出现新 shot；也不能用“转到正面”隐藏不连续视点跳跃。用正文自然语言承载状态，不新增额外的 H3 字段。

特效按 [vfx-design.md](vfx-design.md) 的设计记录与 vfx-families.md 相关类别，写入事件发生处的来源/尺度、主形/运动、接触/环境反馈、受光和余波。世界基准只说一次，源点变化、命中、停供、破损与跨镜烟尘不能被精炼掉。技术名转成可见结果，如薄烟缘透侧光、厚烟遮后景；不贴完整分类表或质量口号，不把体素数、GPU 粒子数、Niagara 或求解器当生成开关。

飞行、击飞、跳跃或坠落按 [continuity-ledger.md](continuity-ledger.md) 的轨迹审计，把地标路径、水平/垂直运动、变速/转向的原因与顺序写进正文；身体姿态和相机运动另述，画面方向由机位推导，不能只留内部台账。尤其不能把“向东飞行，轨迹逐渐下弯”精炼为“下坠”而丢失水平运动。

默认人物正常时间流速；选定慢动作时明确涉及哪段、屏幕占用、需要时的倍率及恢复/结束位置，同时移除矛盾的全片正常速声明。不要为每镜复制长禁令或镜头术语串。

打斗按 [scene-playbooks.md](scene-playbooks.md) 的接触点审计，将每次攻击的攻击者侧别/部位或持握、原目标、实际接触双方的侧别/部位或兵器段位/表面、共同区域与结果写成自然动作句。同镜连招不压成“快速交换三招”；落空/格挡不变成命中原目标，接触中切镜仍接同一对部位，再写滑动/分离。删修辞，不删区分拳对拳、拳对肘、拳对身体或武器触点的词。

武器按 scene-playbooks.md 锁定每件的数量、形制及用户特殊结构；转腕、交叉、快挥、遮挡重现等风险处，保留“哪只手握同一柄—刃根连接—同一刃身/尖部运动”的正向锚。不精炼成“持剑激战”或只堆负面词；素材、概述与逐镜的数量和持握一致。

按 [rhythm-camera.md](rhythm-camera.md) 把同框关系、实际间距、空隙及各人占画尺度写进对应镜头。吃饭可自然同框，远距可共同远景或分别拍；切远人近景时，用观看位置、地标与目线保留原间距。不能只在总述写“相距一千米”，逐镜却把双方放进同一近景挥剑相撞。

## 时间与声音

- 总时间线匹配用户与本轮模式/配置要求，镜号和切点有序；预算按成片屏幕时间计算。请求时长、提示词时间线、实测文件长度分开，不把历史帧数公式或旧通道字符限制当成当前事实。
- 超出当前单段能力时设计分段：每段保存人物/道具状态、空间锚、光源、速度和声场的交接。保留用户全部关键内容，不能用摘要伪装成已容纳全部动作。
- 同步接触声、台词、人声写在对应事件；整体底噪与空间声场放相应声音字段。声源身份遵循 H3，原语言对白/歌词/场内文字照留，不给沉默角色强加发声。
- 打斗中的台词落点、停顿与语气对应当下体力、呼吸和受击状态，并与动作及屏幕时长共同核算。重要对白与复杂动作竞争时，在用户允许的范围内调整节拍、镜长或先后，保留指定台词和动作；不一律禁止边说边动，也不强制每次发力喊叫或每次受击喘气。可辨口型仍按 [cg-look.md](cg-look.md) 对应档位保留同一三维模型面部。
- 距离、遮挡、材质影响响度和混响。J/L-cut 写出实际跨越画面切点的声音，不只是标注名称；慢放中的声音是否同步拉长或用主观处理需与画面一致。
- 默认无配乐，按 H3 明确表达；用户要配乐时按其节奏/氛围设计，剪辑不必机械踩每个鼓点。

## 文件与精炼

默认 `H3-片名-版本.txt`，UTF-8，正文仅含当前模式要求的提示词，无额外标题、代码围栏、自检或中文翻译附录。默认不出中文分镜表；用户明确要求分镜时，提供有用的镜头、时长、动作、机位与转场关系，不能以默认交付习惯拒绝。

正文语言依 H3；回复文件链接和实测字符数（含空白），必要问题简述。按当前工作区约定保存，不覆盖用户旧稿。字符数是长度信息，不是成功率或模型能力证明。

压缩次序：全局重复 → 同义修辞 → 无必要技术参数。保留用户要求、局部 3DCG/三渲二建模身份锚、主特效的来源/作用与残留、前镜末态与本镜初态的动作/空间承接、声音时序和实际参考关系；确实超限时给可执行分段或取舍方案。不用机械禁词扫描代替语义判断，也不为普通写稿建立一次性脚本库。
