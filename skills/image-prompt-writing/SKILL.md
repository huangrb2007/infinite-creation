# 资产出图提示词（配合导演助理）

为角色、场景、道具写出图提示词。这些图是后面 H3 视频的参考素材，导演助理（director-assistant）会按固定分区去读它们，所以版式必须照下面写，不能自创。

## 画风先行

- 画风以项目设置为准（系统提示词里的「项目参数：画风」和风格指南 style）。每条 prompt 开头先写画风关键词，全项目统一，不要写成别的画风。
- 视觉档位跟导演助理一致：默认 3DCG 档、三渲二档或真人电影档（由项目画风决定）。人物皮肤、材质、光影的措辞按该档位写，三档的词不要混用。

## 按资产类型写构图

### 人物 character（16:9 角色设定图）

同一张图里是同一个角色的四个区域，版式固定：

- **上半部分：** 一张大的面部特写（头肩近景）。这是唯一的面部身份来源：脸型、五官、眼形瞳色、肤色、妆容、发际线和刘海都在这里画清楚。
- **下半部分从左到右：** 正面全身、正右侧面全身（角色身体右侧朝向镜头）、背面全身。头顶到脚尖完整入画、不裁切。用来锁定身材比例、服装层次、配饰、鞋子和发型的后部轮廓。
- 四个区域是同一套服装、同一身配饰，比例严格一致；中性站姿，手臂稍离身体。
- 纯浅灰或纯白无缝背景，柔和均匀的棚拍光加一点轮廓光；不出现文字、标注、边框和其他人物。

人物外貌和固定着装逐项写全，这些就是全片的服装锁定，之后视频提示词里不会再重新描述，所以这里写错一件，全片都错。信息按这个顺序写（取自用户的 MiniMax-H3 文戏资产流程）：

```text
画风与棚拍基调 → 国籍与年龄 → 剧情身份与人物状态 → 身高体型与站姿 → 妆面肤质 → 发型发色 → 五官与表情 → 服装结构、颜色与合身程度 → 鞋履、配饰和随身道具 → 版式（上方面部特写 + 下方三张全身）→ 背景和光线
```

- 妆面肤质写成可见结果：哑光、柔雾、无油光；写实档再加「自然微绒肤质、鼻唇过渡平滑」。
- 五官写到能区分：眼形、双眼都睁开且对称、鼻唇、脸型；表情用人物常态（冷淡、懵、警惕），不要夸张。
- 服装写「合不合身」和穿法（领口解开一颗、袖口卷到小臂、裤脚堆在鞋面），这些细节最能防止视频里换装。
- 随身道具写清怎么带（斜挎从右肩到左胯、拎在左手）。
- 同一角色服装、发型、年龄状态不变就只做一张设定图；剧情里明确换装、年代变化或伪装时，才做新的造型（换装 / 年龄变体）。一次性群演不做角色资产。

### 场景 scene（16:9）

- 空场景：画面里没有任何人物。
- 信息按这个顺序写：

```text
地点与时间 → 空间骨架（门、窗、楼梯、电梯、路口在哪一侧）→ 地面、墙面与主要材质 → 家具、门窗、载具和可参与动作的道具 → 前中后景关系 → 光源、色温与主色 → 空气感与生活痕迹 → 视觉风格（写实档可写摄影师 / 胶片 / 镜头光圈；3DCG 和三渲二档写对应的渲染与光影词）
```

- 空间骨架是给导演助理定轴线和人物站位用的，一定要写清左右、前后。
- 同一地点结构不变就复用一张；只有日夜、天气或陈设变化时才做变体。
- 不出现可读的招牌字、标语和水印（视频模型会把字照搬并抖动）。

### 道具 prop（1:1）

- 纯白背景，画面里只有这一个物体，完整入画、居中。
- 写清形状、材质、颜色、磨损和关键细节。剧情需要读出来的文字（短信屏幕、标签）才写，并写清内容；其余不出现文字和 logo。

## prompt 写法

1. 中英文都可以（按上面的信息顺序写，一项一短句）。人物写够细节，场景、道具写清结构和材质即可。
2. 写具体可见的特征，少用「美丽、高级、电影感」这类空词。
3. 人物的中文名不写进 prompt（模型可能把字画出来）。

## negative_prompt

- 通用：`blurry, low quality, pixelated, distorted, watermark, oversaturated, extra people, text overlay, labels, border`
- 人物加：`extra fingers, deformed hands, fused fingers, plastic skin, oily skin, deep nasolabial folds, mismatched outfit between views, different face in lower views`
- 场景加：`people, person, crowd, characters`

## 怎么写入

- 新资产：`create_asset(category, name, description, prompt, negative_prompt)`，人物同时写 `voice_desc`。
- 已有资产：`update_asset(id, {prompt, negative_prompt})`。用户手动保存过的提示词（prompt_locked=1）不要改。
- 全部写好后由流水线统一出图（`generate_assets_batch`），不要逐个单独出图。
- 换装、年龄变体只在剧情真的换衣服、跨年龄段时才做（`change_outfit` / `change_age`），版式与原角色设定图相同。
- 能看图时，先用 `view_asset` 看已有的用户上传图，在它的基础上写，不要另起一套长相。
