# 资产提取：人·物·场三清单

视频模型只会照参考图画；没有参考图的东西，每个镜头都会重新编一次——人换脸、手机屏幕内容乱写、系统光幕每镜一个样。所以资产提取的目标是：**镜头里看得清的东西，都要有资产。**

写完剧本、拆分镜之前做这一步。用 `list_assets` 先看已有资产，已有的同名资产直接沿用、补全描述，不重复建。

## 原则

1. **原文优先**：原文明确写到的外貌、物件、场景直接用；原文没写但身份、职业、年代能推出来的，按推导补；不要编出与原文矛盾的特征。
2. **人·物·场分离**：
   - 角色描述里只写身体和贴身穿戴（衣服、鞋、眼镜、首饰、纹身伤疤）。
   - 能拿起来、能单独摆放的东西，以及会显示内容的屏幕、光幕、纸张，一律进道具清单。
   - 搬不走的环境（墙、地、楼、路、江、天气光线）进场景清单；场景里摆着的可移动物件写成道具，场景描述里只点一句位置。
3. **同一物件不同状态分开建**：内容会变的东西，每个状态一个资产。例如「主角的手机-聊天界面界面」「主角的手机-朋友圈界面」「系统光幕-绑定提示」「系统光幕-四个签到选项」。不变的东西只建一个。

## 清单 A：角色（category=character）

**画面里出现、看得清脸的每一个人都要建角色**，包括只露一两个镜头的配角（骂人的司机、保安、前台）。原文里和主角当面冲突、对骂、说话的人都算出镜角色，不要为了省事改成「只闻其声」。只闻其声、从不出镜的人（电话那头、发短信的人、门外喊话）不建角色图，建一个 `category=voice` 的资产，名字就用人名（如「女友」），`description` 写声线；旁白、系统音同样各建一个 voice 资产（「旁白」「系统音」）。应用会给这些声音生成音色样本，并按台词的说话人自动绑定到对应段落。远景里看不清脸的路人群演不用建。

每个角色写进 `description`（一整段连贯文字）：

- 年龄、性别、身份；
- 身高体型、肤色；
- 发型发色；
- 辨识度最高的 1–3 个五官特征；
- 固定着装：每一件衣服的颜色、款式、材质和穿法，鞋，配饰，随身道具怎么带（斜挎、拎在左手）。

`voice_desc` 写声线（性别、年龄段、音色、语速、口头习惯）。

同一角色只在剧情明确换装、跨年龄段或伪装时才建变体（`change_outfit` / `change_age`），其余一律用同一张设定图。

## 清单 B：道具（category=prop）

道具最容易漏。不要凭印象列，**逐场逐句扫一遍剧本**，每一场先列一张清单，再建资产：

| 扫描什么 | 例子 | 怎么建 |
|---|---|---|
| 人物拿起、使用、递交、丢掉的东西 | 手机、钥匙、信封、咖啡杯、武器、钱包 | 每件一个道具 |
| 镜头会特写或反复出现的东西 | 交通工具、门锁、戒指、合同、药瓶 | 每件一个道具 |
| **会显示内容的东西** | 手机界面、电脑 / 电视屏幕、倒计时、仪表、监控画面 | 每种显示内容一个道具 |
| **画面里要读出来的文字载体** | 短信、信、纸条、通知、证件、招牌、门牌 | 每份内容一个道具 |
| **台词的声源是物件的** | 系统提示、短信朗读、电话那头、广播、导航、语音助手 | 给发出声音 / 显示文字的那个东西建道具 |
| **只存在于设定里、但画面必须看得见的东西** | 系统光幕 / 属性面板、法阵、灵力符文、全息投影、契约卷轴 | 按题材惯例把它具象化，每种状态一个道具 |
| 状态会变的东西 | 完好 / 碎裂的杯子，空 / 满的袋子，关 / 开的箱子 | 每个状态一个道具 |

规则：

1. **声源必须有画面载体。** 台词行头写着「系统」「短信」「电话」「广播」「导航」这类物件声源的（包括 `某人（短信画外音）`），这一段必须绑定对应的道具，应用会检查。网文里用【】或特殊符号标出的系统提示，即使原文说「在脑海里响起」，短剧里也按题材惯例做成浮现在人物面前的半透明光幕 / 面板，面板上显示提示原文。
2. **带内容的道具写清全部内容**：在 `description` 和出图 `prompt` 里写出屏幕或纸面上的完整文字（原文原句，一字不改）、排版（几条消息、谁发的、气泡在左还是右、几个按钮、几栏选项）、配色和发光方式。
3. **一种内容一个道具**：同一部手机的聊天界面和朋友圈界面是两个道具；同一个系统的「绑定成功」和「签到选项」是两个道具。道具名写成「物件-状态」，例如「手机-聊天界面」「系统光幕-签到选项」「合同-签字页」。
4. **不变的东西只建一个**，所有用到它的段落都绑同一个。
5. 场景里固定、不会被拿起或特写的东西（墙上的画、路灯）不用单独建，写进场景描述。

建完后对照剧本再核一遍：每一场里被提到的物件、每一句物件声源的台词、每一块会出现文字的地方，都能在道具清单里找到对应的名字。

## 清单 C：场景（category=scene）

每个独立地点（内外景、白天夜晚分开）建一个场景资产。`description` 用一段大白话写：

- 镜头站在场景正前方稍微俯视，从近到远、从左到右把空间说清：门、窗、楼梯、电梯、路口、沙发、栏杆各在哪一侧；
- 地面、墙面和主要材质；
- 主光源方向、色温和主色调，时间和天气；
- 场景里固定摆着的道具只点一句位置（「门边放着〔道具名〕」）。

场景图里不出现人物。空间左右写清楚，导演助理要靠它定轴线和人物站位。

## 绑定到分镜

- 拆分镜时，每一段的 `characters` 写全画面里出现的每个人（包括背影、半身入画、门缝里露脸的），`props` 写全这一段出现的道具（用到哪个状态就绑哪个状态的资产），`scenes` 写所在场景。
- 只闻其声的人不放进 `characters`，他们的台词写进 narration：`女友（短信画外音）：……`，说话人名字和 voice 资产名一致才能自动绑上音色。
- 对白的说话人必须是角色资产；画外音（电话、门外喊话）写成 `名字（画外音）：……`。

## 出图

清单写完后，出图提示词按 `image-prompt-writing` 写（人物设定图版式、道具白底、场景无人），由流水线统一出图。
