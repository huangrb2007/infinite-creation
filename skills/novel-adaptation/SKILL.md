# 小说 → 短剧剧本（忠实改编）

目标：观众看完这一集，知道的事情和读完这一章一样多；画面能演的交给画面，画面演不了的交给主角的心声，实在没人能说的才用旁白。

## 一、不编造（最重要）

1. 只改编原文已有的情节、人物、对话和物件。原文在哪里结束，剧本就在哪里结束，不续写下一章。
2. 不新增原文没有的事件、人物关系、台词、数字和设定。不改动原文的选择和结果（原文选了「选项一」，剧本里就是选项一）。
3. 允许的改动只有：
   - 一句开场钩子和一句章末悬念（主角心声或旁白都行）；
   - 把原文的叙述改写成主角心声 / 旁白时的措辞调整和压缩；
   - 为心声配的闪切画面（只能画原文提到过的东西）；
   - 为了画面连贯，补一句人物怎么到达下一个地点（「他骑车回到小区」），但不加新事件。
4. 原文里的短信、系统提示、广播等文字，原句照用，一字不改。原文用【】或其它特殊符号标出的系统提示、界面文字写成 `系统（画外音）：……` 这类物件声源行，并在动作描述里写出它在画面里怎么出现（光幕在人物面前展开、手机亮屏、广播喇叭响起）——短剧里物件发出的声音要有画面载体，不只是声音。短信、留言要念出来时由发信人的声音念（`女友（短信画外音）：……`），不要写成收信人的内心独白——否则观众听到的是收信人的声音在念对方的话。

## 二、谁来说话：主角的心声优先，旁白最少

短剧观众跟着主角走。原文的叙述大多可以变成主角自己的心里话，比第三人称旁白更有代入感、更省时间：

1. **贴着主角写的叙述 → 主角的内心独白**。「他用了两分零九秒把自己摔下床」「这土壤太适合他了」这类句子，改成主角第一人称的心声（「两分零九秒摔下床，四分三十九秒到门口」「这土壤太适合我」）。
2. **旁白只留给主角说不了的话**：主角不知道的事、时间跳跃、开场钩子和章末悬念。一集里旁白通常只有几句，没有也可以。
3. **画面能看到的不念出来**：动作、表情、环境、谁走到哪里，写成动作描述行（△ 或括号），不写进旁白和独白。同一件事不要「旁白说一遍、心声再说一遍」。「门纹丝不动」这类描写是画面，不是台词。
4. **心声口语化、压短**：一句心声 8–25 个字，像人在心里吐槽；长句拆短，书面语改口语，删掉「经常……的人都知道」这类铺垫。

每一句能听到的话单独一行，应用靠这个格式分配音色：

- 对白（画面里的人开口说）：`人物名（情绪）：台词`
- 内心独白（嘴不动的画外音）：`人物名（内心OS）：……`
- 旁白：`旁白：……`
- 非人物声音和画外的人声：`系统（画外音）：……`、`女友（短信画外音）：……`、`邻居（门外画外音）：……`

台词文字里不要用【】〔〕和省略号（视频模型会把括号里的内容画成字幕，省略号会被念成拖长音）。

## 三、取舍与节奏

1. **信息不丢，字数要省**：每个情节点、关键心理活动、伏笔都要有，但能用画面交代的一律交给画面。台词 + 心声 + 旁白总字数大约是原文的 15%–25%（3000 字的一章约 500–700 字，成片两分多钟）。超过 35% 就是在念原文，成片会又长又拖。
2. **心声提到的画面要拍出来（闪切）**：主角想到的过去、别的地方、抽象的东西，用一两秒的闪切画面配上，例如想到车祸就切车祸画面，想到「那个年代遍地黄金」就切那个年代的街景，想到「专家都治不好」就切医生看片子。动作描述里写 `（闪切）……`。闪切画面里出现的人和物同样要建资产。
3. **对白一句不能丢**：画面里的人开口说的话全部保留（可以压短），尤其是冲突里的狠话。
4. **开场 3 秒进冲突**：第一个画面就是本章最紧张的状态（倒地、被追、被甩），背景交代往后放。

## 四、格式

```text
【第1场｜傍晚 18:40｜江城十字路口】
出场人物：主角、司机
（动作描述：一两句，写画面里发生了什么）
旁白：……
主角（内心OS）：……
司机（怒骂）：……
```

- 场次按时间或地点变化划分。每场结尾写清人物去向（骑车离开、关门），下一场开头写清怎么到的，给转场留抓手。
- 出场人物写全这一场画面里出现的人，包括配角；只闻其声的人不写进出场人物。
- 章节如果已经是剧本格式（有场次、有「人物：台词」），直接用，不要重写。

写完用 `set_chapter_script` 保存。
